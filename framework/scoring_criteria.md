# Scoring Framework

## Sector Evaluation Criteria

Each sector scored 1-5 on these axes:

| Criteria | Description | Weight |
|---|---|---|
| **AI Leverage** | How much does AI multiply output/speed? | High |
| **Current Adoption** | Low adoption = more room to run | High |
| **Market Pricing** | Has the AI narrative been priced in? | High |
| **Investability** | Can you get exposure with public stocks/ETFs? | Medium |
| **Time Horizon** | Will impact show in 1-3 years? | Medium |
| **Bottleneck Type** | Is the constraint compute (good) or physical/regulatory (bad)? | Medium |

## Company Evaluation Criteria

| Criteria | Description |
|---|---|
| **AI-Native** | Was the company built around AI, or bolting it on? |
| **Moat** | Data moat, regulatory moat, network effects? |
| **Valuation** | Already at AI premium, or still at legacy multiples? |
| **Consensus** | Is every analyst already talking about this? |
| **Catalysts** | Upcoming events that could move the stock? |
| **Risk** | Binary outcomes? Cash burn? Dilution risk? |

## The "Consensus Test"
> If you ask 3 different AI models and they all say the same company, be cautious.
> The best opportunities are ones that require domain knowledge to see.
