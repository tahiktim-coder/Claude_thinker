## Tier 3: Discord (Active Trading Communities)

| Server | What It Offers | Cost |

| **Stock Dads** | Live streams, real-time signals, has in-house CPA/CFP | Paid |
| **Making Easy Money (MEM)** | Run by ex-WSB mod Grandmaster-Obi, called "new WallStreetBets" | Limited access |

**Warning:** Discord trading servers can be pump-and-dump vehicles. Never follow blindly. Use as idea generation only.

## Tier 4: TikTok / FinTok

**Be very careful.** FinTok is mostly:
- Survivorship bias (you see gains, never losses)
- Pump schemes disguised as "tips"
- Entertainment, not analysis

Use as starting point for research ONLY. Never as a buy signal.

## How to Build a Signal Pipeline

1. **Weekly:** Check Capitol Trades + Quiver Quantitative for new congressional filings
2. **Weekly:** Check Unusual Whales for large unusual options activity in our sectors
3. **Monthly:** Review SwaggyStocks for rising WSB sentiment on our watchlist names
4. **Quarterly:** Check WhaleWisdom when 13F filings drop (Feb, May, Aug, Nov)
5. **Before any buy:** Cross-reference against all sources above
