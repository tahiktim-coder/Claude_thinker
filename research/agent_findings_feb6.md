# Simplified Agent System: 3 Not 8

You're right — 8 agents is overkill. Here's the simplified version:

## Agent 1: THE WATCHDOG (Weekly)
Combines: Insider tracking + Catalyst calendar + Sentiment
- Checks politician trades (Capitol Trades)
- Checks executive insider buys/sells (OpenInsider)
- Checks upcoming earnings dates
- Checks analyst upgrades/downgrades
- Output: One weekly summary of what changed

## Agent 2: THE SCOUT (Monthly)
Combines: Second-order effects + Competitor analysis
- Searches for new beaten-down AI plays (like how we found DUOL)
- Checks if competitors are threatening our picks
- Looks for non-obvious AI beneficiaries
- Output: New name suggestions and thesis updates

## Agent 3: THE DOCTOR (Quarterly)
Combines: Portfolio review + Macro check + Devil's advocate
- EUR/USD check
- Interest rate direction
- Are our theses still intact?
- Any position too large? Rebalance?
- Output: BUY / SELL / HOLD for each position

That's it. 3 agents. Run them when you open a new Claude session.
